## Default Shortcuts

| Shortcut | Command |
|---|---|
| `Cmd+Shift+Alt+C` | Path with Line |
| `Cmd+Shift+Alt+X` | Code with Context |

## Suggested Shortcuts for Other Commands

| Command | Suggested Shortcut |
|---|---|
| Full Path with Line | `Cmd+Shift+Alt+F` |
| Relative Path | `Cmd+Shift+Alt+R` |
| Full Path | `Cmd+Shift+Alt+A` |
| All Open Paths | `Cmd+Shift+Alt+O` |
| Symbol Context | `Cmd+Shift+Alt+S` |
| Diagnostics (File) | `Cmd+Shift+Alt+D` |
| Diagnostics (All) | `Cmd+Shift+Alt+E` |
| Remote URL | `Cmd+Shift+Alt+G` |

On Windows/Linux, use **Ctrl** instead of **Cmd**.

## How to Add a Shortcut

1. Open **Keyboard Shortcuts** with `Cmd+K Cmd+S`
2. Search for **"grab"**
3. Click the **+** icon next to the command you want to bind
4. Press your desired shortcut (e.g. `Cmd+Shift+Alt+F`)
5. Press **Enter** to confirm
